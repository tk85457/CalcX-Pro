## 💻 GitHub / About Section

### Short Summary
CalcX Pro is a comprehensive, cross-platform Flutter calculator application. It features a Basic Calculator, a full Scientific Calculator, and a suite of specialized tools including EMI, GST, Currency, and Unit converters. Built with Material Design 3 and optimized for performance on all devices.

### Professional Description for 'About' Section
A feature-rich, high-performance calculator suite built with Flutter. CalcX Pro combines three distinct modes—Basic, Scientific, and Advanced Utility Hub—into a single, optimized package.

**Tech Stack:**
*   **Framework:** Flutter (Material Design 3)
*   **State Management:** Provider
*   **Storage:** Hive (NoSQL)
*   **Optimization:** ProGuard, Tree Shaking, Code Minification

**Calculators Included:** Standard, Scientific, EMI, GST, Unit Converter, Currency Converter (Real-time), Age, Discount, and BMI.
