**Unlock the Power of Precision with CalcX Pro – Your Ultimate All-in-One Calculation Suite!**

CalcX Pro is a comprehensive, lightweight, and elegantly designed calculator application built for everyone—from students and professionals to homeowners and travelers. Whether you need to solve complex equations, plan your finances, or convert units, CalcX Pro is the only tool you'll ever need.

## 🚀 Key Features

### 1. Smart Basic Calculator
*   Fast and reliable standard arithmetic operations.
*   Percentage calculations made simple.
*   Clear/Clear Entry (C/CE) for quick corrections.

### 2. Advanced Scientific Calculator
*   Full suite of trigonometric functions (sin, cos, tan, and inverses).
*   Logarithmic (log, ln) and exponential functions.
*   Powers and Roots (x², x³, xʸ, √, ∛).
*   Built-in constants like π and e.
*   Parentheses support for complex multi-step equations.
*   Factorials for statistical work.

### 3. Specialized Utility Hub
*   **EMI Calculator:** Plan home, car, or personal loan EMIs instantly.
*   **GST/Tax Calculator:** Easily add/remove GST with customizable rates.
*   **Currency Converter:** Real-time exchange rates for global currencies.
*   **Unit Converter:** Length, Weight, Temperature, Area, and more.
*   **Age Calculator:** Exact age calculation and date durations.
*   **Discount Calculator:** Instant savings calculation during sales.
*   **BMI Calculator:** Health tracking with Body Mass Index.

## 🚀 Getting Started

### Prerequisites
*   Flutter SDK (3.0.0 or higher)
*   Android SDK / Xcode

### Installation
1.  Clone the repository:
    ```bash
    git clone https://github.com/tk85457/CalcX-Pro-a-dvanced-calculator-app.git
    ```
2.  Install dependencies:
    ```bash
    flutter pub get
    ```
3.  Run the application:
    ```bash
    flutter run --release
    ```
